# AdNoc

Сервис зарядки электромобилей: тестовое задание. Два интерфейса одного сервиса, собранные в коде по макетам из Figma.

- **Приложение водителя** (`#/mobile`): карта и станция → выбор устройства → подключение кабеля → зарядка → нестандартный сценарий «нет связи со станцией».
- **Веб-панель оператора** (`#/web`): список устройств с фильтрами, поиском, сортировкой и пагинацией; карточка устройства; действия над разъёмом («Завершить сессию», «Заблокировать») через подтверждение.
- **Компоненты и токены** (`#/kit`): всё, из чего собраны экраны.

Данные условные (Санкт-Петербург, станции и тарифы выдуманы), бэкенда нет. Это прототип, а не продукт.

## Запуск

```bash
npm install
npm run dev      # локально
npm run build    # сборка в dist/
```

Сборка уходит на GitHub Pages через `.github/workflows/pages.yml` (Settings → Pages → Source: GitHub Actions).

## Как устроено

- `src/tokens.css` — токены 1:1 с переменными Figma: `Spacing`, `Radius`, `Brand/Lime` и цвета (iOS-библиотека для мобилки, свой стиль для веба). Все отступы и радиусы берутся из них, значения только чётные.
- `src/data.ts` — единые данные для мобилки и веба: станция №144, три устройства, сессия 11 кВт.
- `src/web/` — веб-панель; `src/mobile/` — приложение; `src/kit/` — страница компонентов.

## Про Storybook

Пока не подключён: компонентов мало, и страница `#/kit` показывает то же самое без лишней инфраструктуры. Если компонентов станет больше, добавим Storybook поверх текущих файлов, ничего не переписывая.

## Допущения

Те же, что в Figma: без связи станция продолжает зарядку сама; блокировка разъёма во время сессии срабатывает после её окончания (не подтверждено источниками).
